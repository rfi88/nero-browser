# Nero Browser
Browser ringan berbasis Python (PyQt6) dengan fitur:
- Akselerasi download pakai Aria2c.
- Download video YouTube instan pakai yt-dlp.
- AdBlocker bawaan.

## Cara Install (Fedora)
1. Download file .rpm dari halaman Releases.
2. Install dengan: `sudo dnf install ./nero-browser-1.0-1.noarch.rpm`
3. Jalankan: `nero-browser`
